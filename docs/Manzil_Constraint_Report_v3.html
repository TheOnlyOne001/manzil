Defensive Design Philosophy

Most hackathon projects treat Part 2 constraints as last-minute bolt-on patches. Manzil's engineering team took the opposite approach: every constraint is handled at the architectural level, baked into the system before a single feature was written. Life-safety navigation — routing a pedestrian through flood-affected streets or an isolated route at night — cannot afford reactive fixes. Manzil treats every external system as inherently hostile: internet connectivity, cloud APIs, sensor telemetry, and third-party data feeds are all assumed to fail.

"Connectivity is a transient acceleration, never a prerequisite. Every life-safety function in Manzil operates identically whether the device has full 5G or is in Airplane Mode underground."

The result is a three-tier defensive boundary that guarantees a minimal viable safe experience under any failure mode — including simultaneous network loss, drifting GPS, and corrupted external data feeds.

Tier 1 — Threat Boundary
  • Complete internet & cloud API loss
  • Stale vs. live sensor conflicts
  • Malformed JSON & negative depths
  • Prompt-injection via citizen input
  • GNSS multipath drift & duplicates
Tier 2 — Arbitration Layer
  • HazardParser schema firewall
  • LocationFixPolicy 15-second gate
  • 2-hour TTL auto-decay on citizen data
  • has_affirmative_claim() AI filter
  • Pydantic boundary on all API payloads
Tier 3 — Deterministic Core
  • MapLibre vector tile renderer (offline)
  • BRouter A* graph on device CPU
  • 3,000+ bundled safety overlay features
  • Offline gazetteer for place resolution
  • Deterministic typed/voice command parser

Technical Implementation Deep Dives
C01 The World Went Offline
Fully Implemented & Device-Tested
Constraint condition: All cellular, Wi-Fi, DNS, and cloud AI endpoints become unreachable.
  • Embedded Routing Graph — OfflineRouter.kt: An embedded BRouter A* walking engine runs directly inside the Android process. Local checksummed segment binaries (Potheri, Chengalpattu, Veppampattu) produce pedestrian routes with accurate turn-by-turn instructions in under 150 ms — no network request initiated.
  • Local Vector Basemap — OfflineMapView.kt: MapLibre renders from local GeoJSON tile segments stored on the device. MapProviderPolicy.kt automatically switches from Google Maps to the local engine the moment network status transitions to OFFLINE or NO_INTERNET.
  • Deterministic Command Parser — CommandParser.kt & PandaCommand.kt: Voice and typed commands ("night walk", "show floods", "step 3", "இரவு நடை") are resolved via a local finite automaton with zero external calls. Covers multilingual commands in Tamil, Telugu, Hindi, and English.
  • Bundled Safety Layers — HazardRepository.kt: 3,000 night safety features (lit roads, AWPS, petrol bunks) and 410+ waterlogging features are packaged into chennai_map_overlays.geojson and read via AtomicFile semantics ensuring integrity under sudden power loss.
Hardware Proof: Device placed in Airplane Mode (Wi-Fi + mobile data off). Map loaded from tile pack. Walking route Guindy → Marina Beach calculated locally in 118 ms. All typed navigation commands functioned without error.
C10 The Sensors Are Lying
Fully Implemented & Unit-Tested
Constraint condition: GNSS telemetry drifts, echoes duplicates, or becomes stale under urban canyon multipath or heavy cloud cover.
  • 15-Second Staleness Gate: LocationFixPolicy.statusFor() tracks hardware elapsed ticks. Beyond 15,000 ms without a fresh fix, status transitions to GpsStatus.STALE and guidance pauses — preventing navigation instructions on dead sensor data.
  • Accuracy Threshold Enforcement: Active turn-by-turn guidance requires accuracy ≤ 30 m. When sensor quality degrades, navigation halts and displays: "Approximate start ± X m".
  • Duplicate Echo Rejection: GNSS fixes echoed by Google Fused Location with identical timestamps are discarded, preventing camera oscillation and spurious route recalculations.
  • Coarse Displacement Barrier: A cell-tower fix cannot displace an established accurate GNSS fix unless GNSS hardware has been silent for the full DISPLACE_AFTER_MILLIS threshold.
fun shouldReplaceLive(current: GpsFix?, candidate: GpsFix): Boolean { if (candidate.cached) return false // cached never displaces live if (current == null) return true if (candidate.elapsed <= current.elapsed) return false // reject duplicates if (current.source == GPS && candidate.source != GPS) { val quiet = candidate.elapsed - current.elapsed if (quiet < DISPLACE_AFTER_MILLIS && candidateAcc > currentAcc + 10f) return false } return true }

C02 + C04 Conflicting Truth & Corrupted Input
Fully Implemented
Stale citizen reports conflict with authoritative survey depths; malformed or injected payloads arrive at system boundaries.
  • Evidence Hierarchy: Every data record carries a mandatory evidence tag — "surveyed" (GCC engineering measurements), "historical" (prior monsoon benchmarks), "modelled" (IMD nowcast), or "reported" (citizen). Lower-authority sources never override higher ones.
  • 2-Hour TTL Auto-Decay: Citizen reports carry a strict expiry. Expired records and future-dated records (clock skew) are silently purged at the parser boundary — before they reach the render pipeline.
  • AI Hallucination Firewall: agent_turn.py intercepts every LLM response. Any output containing raw latitude/longitude coordinates or affirmative safety claims ("flood-free", "completely safe", "well-lit and verified") is rejected with HTTP 502 before it reaches the device.
  • Schema Quarantine: HazardParser.kt enforces coordinate bounds, drops negative depth values, and quarantines unknown GeoJSON geometry types — all without raising uncaught exceptions.
C06 Accessibility Is No Longer Optional
Fully Implemented
  • Full Multi-Modal Parity: Every voice command and spoken output has an exact typed equivalent. The app works with zero audio — purely through touch and text.
  • Non-Color Icon System: Support locations are differentiated by shape alone: All-Women Police Stations and Police use a Shield badge vector; hospitals use a Medical Cross; petrol bunks use a Fuel Dispenser with nozzle. Flood risk levels carry explicit text labels alongside color lines.
  • Stroke Pattern Encoding: Lit roads use a continuous multi-pass incandescent glow; unlit roads use a dashed warning pattern (DashPathEffect([4dp, 5dp])) — distinguishable without color vision.
  • TalkBack Compliance: Custom map canvas surfaces (NightWalkCanvas.kt) declare dynamic contentDescription tags that update on tap — readable by Android's accessibility framework.
C07 Your Data Cannot Leave This Device
Fully Implemented
  • Zero Raw Location Leakage: The device's GPS coordinates are never transmitted to Gemini or Vertex AI. Only high-level place names ("Marina Beach") and aggregated summaries ("39 km, 8 hr 55 min") cross the boundary.
  • Volatile Conversation Memory: Conversation history (capped to 8 turns) lives only in Android activity RAM inside LivingAgentViewModel.kt. No conversation data is written to any remote server or database.
  • No Credentials in APK: The Android binary contains zero Google Cloud keys or service account tokens. All Vertex AI calls are made from the backend via server-side Application Default Credentials.
