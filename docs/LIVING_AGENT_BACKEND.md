# Conversational Panda — implemented 6 November 2026

## Running integration
Android native SpeechRecognizer (explicit tap) or typed request -> POST /api/v1/agent/turn -> Vertex Gemini `gemini-3.1-flash-lite`, global -> validated structured action -> Android map state. Native TextToSpeech replies are requested only for spoken turns. This is a turn-based conversational agent, not Gemini Live streaming audio or a background wake-word service.

Google Cloud project: project-69f64060-ab6d-43fd-b01. Backend uses existing Application Default Credentials; no credentials or Gemini API keys were embedded in the APK. No billing changes or service enablement were made. Actual remaining trial credit was not inspected.

Backend entry: backend/app/agent_turn.py, Gemini transport: backend/app/gemini_agent.py. Runs on 127.0.0.1:8011; Samsung reaches it through adb reverse tcp:8011 tcp:8011. It currently depends on this workstation backend and USB forwarding. Production hosting, app authentication and per-user quotas are not deployed. Do not expose this development endpoint publicly.

## Actual map actions
- plan_route: canonical English destination query resolves against actual saved places; current location replaces any manual start; route calculation remains Google online / local offline. Night preference selects Night Walk. It does NOT compare route alternatives for safety or prioritize lighting in the routing engine.
- show_layer: Night Walk, flood context or plain map; preserves destination and route.
- recenter: map centers on the phone location; requests missing permission normally.
- route_summary: model receives measured route distance/estimated duration and preview/guidance state.
- none: conversational response or clarification without a map change.

Unresolved or ambiguous destinations go to place selection. Unknown coordinates are never generated by Gemini. Request history is bounded to eight messages and stays in activity memory, not a server conversation database. Closing/backgrounding cancels pending execution; late responses cannot execute actions. Current route success receipts are generated by Android after the route finishes, not by model prose.

One bounded model call per turn, capped output (400 tokens), 20-second ceiling, strict response schema, action validation, no retry storms. Cloud unavailable means a visible error and no model action; existing offline navigation remains accessible.

## Limits
Night lighting and support places are context, not a guarantee of safety or a safety-ranked route. Flood context is historical; the agent does not claim present water depth or analyze intersections between flood evidence and the current route. No emergency calls, external app operations or arbitrary tool execution are exposed. Native speech recognition/voice availability depends on the phone and installed language services.
